# v1.0.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the verified Windows and macOS Apple Silicon installer as GitHub Release `v1.0.0` with accurate unsigned-build guidance and upstream acknowledgements.

**Architecture:** Keep the existing tag-driven GitHub Actions release flow. Add the application version to the package metadata and runtime banner, update documentation to reflect the verified macOS Apple Silicon workflow and permanent unsigned status, and preserve the existing architecture-specific release assets and checksum generation.

**Tech Stack:** Node.js 20, `node:test`, npm, GitHub Actions, `pkg@5.8.1`, macOS DMG packaging, Git tags.

## Global Constraints

- Release tag is `v1.0.0`.
- Windows artifacts remain native x64 and ARM64 only; no x86 artifact.
- macOS artifact is Apple Silicon (`darwin/arm64`) only; Intel remains unsupported.
- Windows and macOS installers remain unsigned and macOS remains unnotarized; no future signing promise is documented.
- Release includes architecture-specific installers, `SHA256SUMS.txt`, and `THIRD-PARTY-NOTICES.md`.
- Product provenance must state that upstream binaries are not built, modified, or hosted by this project.
